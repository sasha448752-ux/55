# CANVASO: приём и просмотр заказов

## Что уже реализовано

- клиент загружает фотографию, выбирает размер и оформляет заказ;
- фотография сохраняется в закрытый Supabase Storage bucket `order-photos`;
- данные заказа сохраняются в таблицу `orders`;
- `admin.html` — закрытая страница для просмотра заказов и изменения статуса.

## Настройка Supabase

1. Создайте проект на https://supabase.com/dashboard.
2. Откройте **SQL Editor**, вставьте и выполните содержимое `supabase-setup.sql`.
3. В **Authentication → Users** создайте пользователя-администратора с email и паролем.
4. Скопируйте UUID этого пользователя и выполните последнюю строку из `supabase-setup.sql`, заменив значение UUID.
5. В **Connect** скопируйте Project URL и `anon` / `publishable` key.
6. В `supabase-config.js` замените оба значения-заглушки. Используйте только публичный ключ. `service_role` ключ в сайт добавлять нельзя.
7. После публикации откройте `admin.html` на адресе сайта и войдите с созданным email и паролем.

## Важно

Текущая версия собирает заявку и сохраняет её в базу. Для приёма онлайн-оплаты нужно отдельно подключить платёжного провайдера (например, ЮKassa) через серверную функцию — секретные платёжные ключи нельзя размещать в GitHub Pages.
